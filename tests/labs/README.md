# Laboratorios de pruebas

Ubicación reservada para experimentos exploratorios sobre **nuestro propio software**, separados de los tests de regresión.

Si un experimento demuestra un comportamiento verificable y estable, debe convertirse en un test automatizado dentro de `tests/unit/`, `tests/integration/` o `tests/gui/`, según corresponda.

No almacenar aquí archivos privados de usuario, registros sensibles ni binarios de terceras aplicaciones.
